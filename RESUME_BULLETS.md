# Resume bullets for the project

**Project: Customer Acquisition, LTV & Investment Optimization Analytics**

Use only after running the project and being comfortable explaining the methods. Keep the synthetic-data context clear if asked in an interview.

- Built a Python-based marketing analytics pipeline on 24,000 synthetic prospect records across 5 markets, comparing welcome-offer performance using conversion rates, acquisition cost, projected 36-month LTV, LTV:CAC, and ROI scorecards.
- Evaluated Standard and Premium welcome offers against a no-offer control using two-proportion hypothesis tests with Bonferroni adjustment; quantified incremental conversion, incentive investment, and estimated incremental value.
- Forecast monthly acquisition conversions for 12 months with SARIMAX, evaluated a six-month holdout using MAE/RMSE/MAPE, and created an interactive Streamlit/Plotly dashboard for KPI monitoring and business insights.
- Prepared Hive and BigQuery SQL templates plus an optional PySpark aggregation pipeline for offer-level reporting.

**Important:** The records are simulated; these bullets describe project scope, not real customer outcomes or American Express work. Remove the SQL/PySpark bullet or any technology that you have not personally executed and understood.
